# Baldwin Palantir

Interactive deal screener for Prague land development: every development and transformation area of the Metropolitní plán, with regulated floor area (HPP), price-map land prices, metro distance, flood risk and the cadastral parcels inside, plus multi-area / multi-parcel selection for land assembly.

**Live map:** https://artur20papp-source.github.io/baldwin-palantir/

Build: `python make_map.py` (writes `index.html`).

Data: © IPR Praha (CC BY) · ČÚZK (parcels, RÚIAN) · PID / ROPID (CC BY).
